# ジェットボート

ビヘイビアーパックと `resource_pack` の両方を有効にしてください。

通常のボート・チェスト付きボートはそのまま使用でき、自動変換しません。
ジェットボートは木材別に分かれない1種類のアイテムです。青緑の船体とエンジンの専用アイコンで通常ボートと区別できます。

作業台で板材5個を通常ボートと同じ形に並べます（板材タグ対応、混在可）。

```text
板 空 板
板 板 板
```

通常ボートと材料・配置が重なるため、レシピ一覧でジェットボートを選択してください。手動配置時の出力競合とレシピ選択は対象バージョンのゲーム内で確認が必要です。

水面に使用すると、従来の高速エンティティ `extensiontrader:fast_boat` を設置します。新規設置はオーク色で統一します。破壊時はジェットボートアイテムに戻ります（クリエイティブではドロップしません）。
既に設置された高速ボートは引き続き動作します。旧チェスト付き高速ボートの回収時はジェットボートとチェストを返します。

3席、船尾でのMob乗船、プレイヤーへの操縦席の譲渡、旋回上限10度/tickは従来どおりです。水上速度設定は `minecraft:underwater_movement.value: 0.3`、地上は `minecraft:movement.value: 0.0375` です。

ゲーム内では通常ボートが変換されないこと、クラフトの選択、水面への設置、浮力・操作・衝突・降船、サバイバル／クリエイティブの回収、旧チェスト付き高速ボートの収納品回収を確認してください。
