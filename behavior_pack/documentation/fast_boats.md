# 高速ボート

ビヘイビアーパックと `resource_pack` の両方を有効にしてください。表示用パックがないとカスタムボートが正しく表示されません。

通常のボートアイテムを設置すると高速ボートへ自動変換します。設置済みのボートもチャンク読み込み後、最大5秒程度で変換します。乗客がいるボートは降船してから変換します。チェスト付きボートの27スロットは変換時に引き継ぎます。

操縦は乗り物用の移動コンポーネントによる操作です。標準ボートのオール式操縦とは異なります。水上速度の設定値は `minecraft:underwater_movement.value: 0.3`、地上は `minecraft:movement.value: 0.0375` です。標準ボートとの実際の速度比は未測定です。

`/summon extensiontrader:fast_boat` または `/summon extensiontrader:fast_chest_boat` でも設置できます。10種類の木材の色を引き継ぎます。モデルは専用の簡易ボートモデルです。

ゲーム内で浮力、操作、衝突、降船、破壊時の回収、チェストのアクセス・引き継ぎを確認してください。自動変換はエンティティを置換するため、他のアドオンが付けた独自のタグやデータは引き継ぎません。

通常・チェスト付きの両方が3席です。モデルは90度回転し、20%拡大しました。船尾に接触したMobが空席へ乗ります。先にMobが乗っていた場合、プレイヤーの乗船時に操縦席を譲ります。旋回上限は10度/tickで、外部エンティティから押されない設定です。
